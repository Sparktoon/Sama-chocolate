# Sama-chocolate
- Project Name: Sama chocolate
- Project Idea: Sama, is an Egyptian plain chocolate brand made by Al Ahmady chocolate industries. Sama was chosen for its identity being a local brand that is admired for its original taste and sensible price. A collection of products was produced under the same name united in purpose. it's clear that Sama adds the perfect touch to whatever dessert it was used at. We as Sparktoon want these feelings to be represented to the locals encouraging them to not miss out such pleasure.
